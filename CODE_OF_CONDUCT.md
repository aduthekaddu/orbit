# Code of conduct

Orbit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, reviews, and any other project space.

To report behavior that breaks it, contact the maintainer privately through the [aduthekaddu GitHub profile](https://github.com/aduthekaddu). Reports are kept confidential.
