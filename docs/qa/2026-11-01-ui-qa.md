# UI QA, 2026-11-01

Branch `feat/design-system`. Desktop at 1440x900 and mobile at 390x844. Screenshots are in `docs/qa/screenshots/`.

## Setup

- App: `next start` on `127.0.0.1:3212` from a copy of the worktree at `/tmp/orbit-qa/app`. Its SQLite file and auth secret live under `/tmp/orbit-qa/app/data`, so `data/orbit.db` in the repo was not written.
- Browser: Playwright 1.64.1, headless Chrome from `/usr/bin/google-chrome`.
- Mock provider: `127.0.0.1:3214`, OpenAI-compatible, models `mock-fast` (no reasoning), `mock-thinker` (reasoning), `mock-slow`, `mock-long`, `mock-fail`. It rejects a bad key and returns 500 for `mock-fail`.
- Real provider: `https://opencode.ai/inference/go/openai/v1`, model `deepseek-v4.1-flash`, key read from `~/kodus/.env` and passed through the environment. The key was never printed and does not appear in a screenshot.

## Checks that passed

- Signup, second signup rejected (403 "Signup is closed"), sign in, wrong password message, sign out, logged-out redirect to `/login`.
- Empty chat with no provider (plug figure, "Open settings") and with a provider (dish figure, "What's on your mind?").
- Settings: base URL, key, model list (28 real models, 5 mock models), Custom model field, reasoning control hidden for a model whose metadata says reasoning is unsupported, effort saved and restored, key never returned by the API and shown only as "Key set".
- Chat streamed from the mock provider and from the real provider. Reasoning renders under a "Thought" disclosure.
- Long reply with a code block, table, list, and prose. Long user message. A 600 character unbroken string.
- Stop mid-stream. Partial text stayed after reload. Send returned.
- Provider error. After the retry backoff the error box appeared, the run ended, and Send returned. See observation O1.
- Reload persistence for one and two turns.
- Sidebar history, recency group, collapse with Ctrl+B and persistence across reload.
- Command palette with Ctrl+K, filtering, Enter, Escape, focus return.
- Keyboard: Tab focus ring, Shift+Enter newline, Enter send, Ctrl+Shift+O new chat.
- Mobile drawer, drawer close on Escape, palette open, settings, long code, no horizontal page overflow at 390px.
- Unauthorized API calls return 401. A missing chat id renders the 404 page.

## Findings

| # | Severity | Finding | Status | Fix |
| --- | --- | --- | --- | --- |
| 1 | High | Assistant replies duplicated in SQLite on the next turn, so a reload showed each reply twice. The stream sent no assistant message id, so the client and the server stored different ids for the same message. Evidence: two `assistant` rows for "turn one". | Fixed | `b3614bb` |
| 2 | High | Regenerate replaced the reply on screen but left the old reply in SQLite. Reload then showed both replies, and Copy copied both. | Fixed | `c7327e7` |
| 3 | Medium | A valid but unreachable base URL, or a rejected key, showed a green dot with "0 models" instead of a failed connection. `/api/models` returned 200 with an empty list for every failure. | Fixed | `b8b0fa9` |
| 4 | Low | A failed turn left an empty assistant message in the message list. The next send stored it as a blank row. | Fixed | `fe01d31` |
| 5 | Low | The settings save error stayed on screen after the field was corrected, until the next save. | Fixed | `e56c892` |
| 6 | Low | Escape on the command palette left focus on `body`. Typing did nothing until the composer was clicked. | Fixed | `04ce4c0` |

### Observations without a code change

O1. A provider error shows the "Thinking" shimmer for about 7 seconds before the error box. The AI SDK retries a failed request twice with backoff. The run does settle and Send returns. Screenshot: `docs/qa/screenshots/desktop-chat-error.png`. A shorter retry budget is a product call, not a defect.

O2. A stopped stream keeps the partial reply and loses the partial reasoning. The assistant row is written only when text exists.

O3. The model list request on mount starts a second request when the base URL or key field blurs. The newest response wins, so this is only extra traffic.
